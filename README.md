# 個人製作

1:C++で制作したゲーム作品「とまれない」
2:C++で制作したゲーム作品「跳弾」

## プログラム担当箇所

各作品の「プロジェクト/個人製作/game/src/game/」main.cppを除くフォルダ内のプログラム全般を担当しました。

## 開発環境

- C++
- Visual Studio
- AQUA Game Library

## 素材について

画像生成AIやフリー素材を使用しています。

## 使用ライブラリについて

### AQUA Game Library

学校から配布されたAQUA Game Libraryを使用しています。

AQUA Game LibraryはDXLibを利用したゲーム制作向けのライブラリです。

### 使用箇所

ゲーム全体のプログラムで使用しています。

主に以下の処理で使用しています。

- ゲームフレームワークの初期化・更新
- ウィンドウ情報の取得
- デルタタイムの取得
- ゲームオブジェクトの検索
- 画面のクリア

### 備考

AQUA Game Libraryは自作したものではなく、
学校から配布されたライブラリを使用しています。

## 実行方法

1. `実行ファイル.zip`をダウンロードしてください。
2. ZIPファイルを解凍してください。
3. 解凍したフォルダ内の`game.exe`を実行してください。
